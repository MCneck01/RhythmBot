Anime Vanguards: Music Note Macro (Open Source)
แจกสคริปต์มาโครสำหรับกดโน๊ตเพลงในแมพ Anime Vanguards ครับ ตัวนี้ผมพัฒนาขึ้นมาเพื่อเป็นการศึกษา สำหรับใครที่ต้องการนำไปพัฒนาต่อยอด หรือปรับปรุงระบบให้ดียิ่งขึ้นสามารถนำไปใช้ได้เลยครับ!
⚙️ การตั้งค่าที่จำเป็น (Prerequisites)
เพื่อให้มาโครทำงานได้อย่างแม่นยำ โปรดตั้งค่าเครื่องดังนี้:
Display Resolution: 1920 x 1080

⚠️ ข้อจำกัดในปัจจุบัน (Known Issues)
Long Notes: ปัจจุบันระบบยังไม่รองรับการกดโน๊ตแบบลากยาว (Hold Notes) มาโครจะทำงานได้ดีเฉพาะการกดแบบจังหวะเดียว (Single Tap) เท่านั้น

สอบถามเพิ่มเติม
หากมีข้อสงสัยเกี่ยวกับการใช้งาน หรืออยากเสนอแนะแนวทางการปรับปรุง สามารถสอบถามได้ตลอดเวลาครับ ยินดีแลกเปลี่ยนความรู้กับทุกคน!
